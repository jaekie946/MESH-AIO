#### 핵심 및 메뉴

- v2.26.0은 사용자 승인 AIO 17개를 전수 색인해 현대 챔피언을 수작업 전용 28 + 생성 전용 145로 구성합니다. 공용 진입 챔피언은 0명이며, 173명 모두 개별 profile/menu/dmg/main 계약을 가집니다.
- League Classic(JADE) 60명도 각 챔피언별 4파일 전용 모듈과 exact route를 사용합니다. FXT 구형 형상 59명과 Rammus 안전 폴백을 유지합니다.
- URF는 현재 Riot의 기본 300 ability haste 규칙과 live 슬롯 준비를 분리해 처리하고, 변신 HUD는 비활성 폼 추정에만 쿨다운 공식을 사용합니다.

#### Nunu

- URF에서 E/재시전를 첫 공격 안전 live-ready 틱에 재시도하는 전용 경로를 추가했습니다. 평타 windup과 R 채널을 보존하고 서버 spell lock을 우회하지 않습니다.

#### Evelynn

- URF에서 Q/Q2를 첫 공격 안전 live-ready 틱에 재시도하는 전용 경로를 추가했습니다. 평타 windup을 보존하고 서버 spell lock을 우회하지 않습니다.

#### Nidalee

- [Viktor]AIO 승인 이미지와 공식 랭크별 쿨다운을 연결해 반대 폼 Q/W/E/R HUD를 추가했습니다. 자기 exact spell 이벤트와 live ability haste를 사용하며 위치·글꼴 옵션을 제공합니다. 공식 형태 7개는 그대로 유지합니다.

#### Jayce

- [Viktor]AIO 승인 이미지와 공식 랭크별 쿨다운을 연결해 반대 폼 Q/W/E/R HUD를 추가했습니다. 자기 exact spell 이벤트와 live ability haste를 사용하며 위치·글꼴 옵션을 제공합니다. 공식 형태 8개는 그대로 유지합니다.

#### Core & Menu

- v2.26.0 inventories all 17 user-authorized AIO archives and routes modern champions as 28 hand-tuned plus 145 generated specialists. No champion remains on a generic entry path; all 173 have individual profile/menu/dmg/main contracts.
- All 60 League Classic (JADE) champions now use per-champion four-file specialist modules and exact routes, retaining 59 FXT old-kit geometry sets plus the conservative Rammus fallback.
- URF separates Riot's current 300 base ability-haste rule from live slot readiness, and transform HUD cooldown math is used only for inactive-form estimates.

#### Nunu

- Added a URF specialist path that retries E/recasts on the first attack-safe live-ready tick. It preserves AA windup and the R channel and never bypasses the server spell lock.

#### Evelynn

- Added a URF specialist path that retries Q/Q2 on the first attack-safe live-ready tick. It preserves AA windup and never bypasses the server spell lock.

#### Nidalee

- Added an opposite-form Q/W/E/R HUD using authorized [Viktor]AIO images and official per-rank cooldowns. It tracks exact local spell events and live ability haste with position/font controls, while retaining all 7 official forms.

#### Jayce

- Added an opposite-form Q/W/E/R HUD using authorized [Viktor]AIO images and official per-rank cooldowns. It tracks exact local spell events and live ability haste with position/font controls, while retaining all 8 official forms.
