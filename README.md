#### 핵심 및 메뉴

- v2.25.1은 케이틀린 Flee E의 투사체 방향과 반동 착지 방향을 분리해, `Z`를 누르면 마우스 방향으로 도주하도록 복구합니다.
- 공통 Semi Q/W/E/R과 완전히 같은 단일 Manual 행동은 Champion Actions에 다시 등록하지 않아 Hanbot 전역 단축키 목록의 MESH 중복을 제거합니다.
- Hex Door·Soul Picking·Auto-Spacing·Evade Toggle은 MESH 소스와 배포 파일에서 등록하지 않는 다른 활성 모듈/내장 기능의 단축키입니다.

#### Caitlyn

- Flee(`Z`) 중 E가 마우스 쪽으로 발사되던 방향 오류를 수정했습니다. 이제 실제 390유닛 반동 착지점을 마우스 방향으로 안전 검사하고, 투망은 마우스 정반대 750유닛으로 발사합니다. 공통 Semi Q/W/E와 중복되던 Manual Q/W/E 및 케이틀린에 맞지 않던 공용 Mobility 단축키도 메뉴에서 제거하고 E -> Flash 같은 고유 동작만 유지합니다.

#### Core & Menu

- v2.25.1 separates Caitlyn E projectile direction from recoil landing direction, restoring cursor-directed escape while Flee (`Z`) is held.
- Single-slot Manual actions identical to native Semi Q/W/E/R are no longer registered in Champion Actions, removing MESH duplicates from Hanbot's global hotkey list.
- Hex Door, Soul Picking, Auto-Spacing, and Evade Toggle are registered by other active modules or built-in features; MESH does not declare those labels in its source or packaged files.

#### Caitlyn

- Fixed Caitlyn E aiming toward the cursor during Flee (`Z`). The runtime now safety-checks the actual 390-unit recoil landing toward the cursor and fires the net 750 units in the opposite direction. Removed duplicate Manual Q/W/E entries already covered by Semi Q/W/E and hid the inapplicable generic Mobility key, while preserving unique actions such as E -> Flash.

#### 核心与菜单

- v2.25.1 将凯特琳 E 的投射物方向与后坐落点方向分离，恢复按住逃跑键（`Z`）时朝鼠标方向撤离。
- 与原生 Semi Q/W/E/R 完全相同的单技能 Manual 动作不再重复注册到 Champion Actions，从 Hanbot 全局按键列表中移除 MESH 重复项。
- Hex Door、Soul Picking、Auto-Spacing 与 Evade Toggle 来自其他启用模块或内置功能；MESH 的源码和打包文件都没有注册这些名称。

#### Caitlyn

- 修复凯特琳在逃跑（`Z`）时朝鼠标方向施放 E 的错误。现在会先按鼠标方向检查实际 390 距离的后坐落点，再向鼠标正反方向 750 距离发射绳网。菜单同时移除与 Semi Q/W/E 重复的 Manual Q/W/E 和不适用于凯特琳的通用位移键，仅保留 E -> Flash 等专属动作。
